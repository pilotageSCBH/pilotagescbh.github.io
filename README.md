# Pilotage BTS SCBH

Application web de pilotage pédagogique du BTS Systèmes Constructifs Bois et Habitat :
séquençages des matières professionnelles, élèves, référentiel, et bientôt progression, fiches et validation des compétences.

- **Site** : fichiers de ce dépôt, publiés par GitHub Pages (aucune installation).
- **Données et comptes** : Supabase (base PostgreSQL protégée par des règles de sécurité).
- **Réglages** : `config.js` (adresse du projet Supabase et clé publique).
- **Base de données** : `sql/1_structure.sql`, à exécuter dans Supabase (SQL Editor).

Aucune donnée d'élève n'est stockée dans ce dépôt.
